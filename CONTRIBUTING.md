# Contributing to TextDetection

Thank you for your interest in contributing to **TextDetection**!

## Great Places to Contribute

- Add Photo Library selection and VisionKit live text scanning (`DataScannerViewController`).
- Improve fuzzy/BM25 retrieval accuracy and math formula handling.
- Add modular exam-paper importers for additional subjects and exam boards.

## Workflow

1. Fork the repository and create a branch (`feat/...` or `fix/...`).
2. Open `TextDetection.xcodeproj` in Xcode and verify the iOS target builds cleanly.
3. Keep changes focused and avoid committing `.DS_Store`, API keys, model weights, or user-specific IDE state (`xcuserdata/`).
4. Open a pull request describing what changed and how you verified it.
